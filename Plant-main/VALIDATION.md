# 확인한 내용과 확인하지 못한 내용

이 문서는 로컬 작업 환경에서 실제 수행한 검사와 한계를 구분해 적습니다.

## 수행한 검사

- 제공된 `shapefiles.zip`: `.shp`, `.shx`, `.dbf` 대응 관계 647세트 확인. DBF 헤더 기반 다각형 105,155건, 점 28,243건, 총 133,398건 확인.
- 모든 새 Python 모듈 `compileall` 구문 검사 통과.
- Plotly 차트 생성: 소실 후 상태, 주변 점유율, 모델 비교, 공간 변화 지도 함수가 테스트용 입력에서 Figure 객체를 반환하는 것 확인.
- 원래 Codex 가공 결과와 변경 버전의 중요한 파일 SHA-256 대조: `grid_analysis.parquet`, `grid_maps.parquet`, `model_metrics.csv` 원본과 동일함.
- 두 최종 ZIP을 `testzip()`으로 검사하고 Streamlit 실행에 필요한 소스 및 데이터 파일이 모두 포함되어 있는지 확인.
- `st.caption()`, `st.metric()` 호출: 새 `app.py`에서는 사용하지 않음.

## 수행할 수 없었던 검사

- 현재 실행 환경에서 `streamlit`, `pyarrow`를 사용할 수 없었고 패키지 설치 네트워크 접근도 실패함. 따라서 **새 앱을 Streamlit 서버로 실행하거나 실제 브라우저에서 레이아웃/모바일 동작을 검수하지 못함.**
- 원자료로부터 모든 가공 Parquet와 학습 모델을 독립 재구축하지 않음. 원자료 ZIP의 형식 및 개수 감사와 기존 계산물 보존을 검증한 것임.
- GitHub 업로드 및 Streamlit Community Cloud 공개 배포는 수행하지 않음.
