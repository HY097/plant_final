# 이번 개편에서 변경한 내용

## 이전 재설계 버전과 비교

1. 6개 라디오 화면을 4개 큰 탐색 단위(연구 이야기 / 지도 탐색 / 조건과 예측 / 자료와 방법)로 재편했습니다.
2. 첫 화면을 연구 방법 소개가 아닌 **실제 소실 후 상태 분류 194건**과 그 의미에서 시작하도록 바꿨습니다.
3. 기존의 의미가 약한 2009–2010년 피복 지도 쌍 대신, 실제 변화가 나타나는 연도쌍 중 중간 수준의 소실률 사례를 자동 선택하는 지도 예시를 배치했습니다. 선택 기준을 코드와 본문에 공개했습니다.
4. 두 연도의 피복 히트맵은 지도 탐색 화면으로 이동했습니다. 핵심 지도는 종의 기록 유지·신규·불확실 상태를 직접 표시합니다.
5. 반복적인 KPI, 회색 보조 문구, 부제, 동일한 카드 배열을 제거하고, 본문·차트·해석 순서로 편집했습니다.
6. 소실 상태 차트, 주변 타종 점유율 차트, 예측 성능 비교 차트의 제목과 범례·축을 정리했습니다.
7. 가공 데이터의 주요 해시와 상태별 사례 수를 확인할 테스트를 추가했습니다.
8. 사용자가 제공한 원자료 Shapefile ZIP의 구성·DBF 레코드 수를 검사하는 독립적인 스크립트를 추가했습니다.
9. GitHub와 Streamlit Cloud 배포 방법을 README에 구체적으로 기록했습니다.

## 이번에 변경하지 않은 내용

- 기존 Parquet의 점유·소실 판정 및 학습·평가 표본
- 기존 로지스틱 회귀 학습 결과와 평가 지표
- 기존 데이터의 가정, 식별 불확실성 처리 기준

## 아직 필요한 검증

- 이 실행 환경에는 Streamlit과 PyArrow가 설치되어 있지 않고 설치용 네트워크 접속도 실패하여 **실제 Streamlit 서버 실행과 브라우저 E2E 검수는 수행하지 못했습니다.** 정적 코드 검사, 도표 함수에 대한 가능한 단위 테스트, 원자료 파일 헤더 확인을 수행했습니다.
- GitHub 저장소 업로드나 Streamlit Cloud 배포는 이 ZIP 생성만으로 완료되지 않습니다.
