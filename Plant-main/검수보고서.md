# 초원 식물 공간 점유 웹사이트 검수 결과

검수 기준: `초원_공간점유_웹사이트_GitHub_업로드용.zip`과 사용자가 제공한 `shapefiles.zip`.
검수일: 2026-11-01

## 판정

**조건부 통과.** 저장소의 필수 파일은 준비됐고 ZIP 손상은 발견되지 않았다. 주요 그래프와 집계 수치도 확인했지만 실제 Streamlit 앱이 실행되는지는 미확인 상태이므로 GitHub 업로드 후 CI와 실제 배포 동작을 반드시 확인해야 한다.

## 실제 확인한 항목

- ZIP 목록 및 무결성 확인, 코드 컴파일 검사 통과.
- 원자료 감사 스크립트 실행: Shapefile 묶음 647개, DBF 헤더 기준 다각형 105,155건, 점 28,243건. 이것은 지오메트리 유효성이나 분석 결과의 독립 재현 검증이 아니다.
- CSV 집계 대조: B. gracilis 단독 점유 소실 194건(타종 신규 기록 75, 식별 불확실 94, 다각형 식물 기록 없음 25).
- 주변 타종 점유 비율 구간별 소실률: 4.3601%, 4.6674%, 12.3124% (저장된 q1 CSV 기준).
- 모델 지표: 평가 사례 400건(양성 91건), 기준 모델 AP 0.427414, 주변 정보 모델 AP 0.441739.
- Plotly 그래프: 소실 후 상태, 주변 식생, 예측 모델, 방목 비교를 별도로 렌더링. 모바일 390px 너비에서 요소가 페이지 밖으로 넘어가는 현상은 관찰되지 않았으나 일부 텍스트가 촘촘하다.
- 공간 변화 지도는 **모의 10x10 자료**로 그래프 함수의 색상과 범례를 검사했다. **실제 연구 Parquet 지도 렌더링 검증을 의미하지 않는다.**
- 별도 오프라인 검사 3개 통과.

## 수정한 문제

**방목 처리군을 선으로 연결해 시간 추세처럼 보이게 하던 문제.**
범주 간 연결선을 제거해 목장별 점 비교로 교체하고, 가로축은 시계열이 아니라 처리군임을 본문에 명시했다. 수정 그래프를 브라우저 엔진에서 데스크톱·모바일 너비로 렌더링해 확인했다.

## 배포 전에 반드시 확인할 항목

1. GitHub Actions `Verify research app` 초록색 완료 여부. 의존성(`streamlit`, `pyarrow`) 설치가 필요하다.
2. Streamlit Community Cloud에서 `app.py`로 배포해 네 페이지가 모두 열리는지 확인.
3. 식물종·조사구·연도·단독 점유 체크박스·연도 범위·식별 오류 제외 조건을 각각 변경하여 표시되는 결과가 달라지는지 확인.
4. 390px 폭 모바일 화면에서 웹 전체의 지도 범례와 긴 데이터 표가 잘리는지 확인.
5. 전체 재현성을 요구한다면 원자료에서 Parquet와 예측 모델을 다시 생성하는 원래 연구 파이프라인을 별도로 확보해야 한다. 현재 저장소에는 가공 결과물과 시각화 코드가 있고, 모델을 재학습하는 전체 파이프라인은 없다.
6. 원자료와 가공 자료의 공개 재배포 조건 및 코드 라이선스를 별도로 점검.

## 결론의 범위

이번 검수는 **현재 저장된 가공 결과의 표시와 배포 파일의 준비 상태**를 확인한 것이다. 모델 지표를 test_predictions.parquet에서 직접 재계산하거나 원본 Shapefile을 전체 공간 분석 과정에 다시 투입하지 않았다. 따라서 원시 데이터로부터 연구 전체를 독립 검증했다고 주장하지 않는다.
