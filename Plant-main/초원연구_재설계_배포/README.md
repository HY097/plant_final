# 초원 식물 연구 — 웹사이트 재설계

처음 방문하는 독자가 연구를 이해하고 실제 관측을 탐색하는 Streamlit 앱입니다. 기존 `final/revision`은 수정하지 않았습니다. 이 폴더의 내용을 저장소 루트에 배포합니다.

## 실행
Python 3.13을 사용합니다. 이 README가 있는 폴더에서 실행하세요.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py --server.port 8503 --global.developmentMode false
```

실행 후 터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.

## 파일 구조
```
app.py                  여섯 화면의 설명·탐색·필터
research.py             공통 집계·지도·그래프
.streamlit/config.toml  밝은 자연색 테마
data/                   사전 계산 자료와 출처·관측표
requirements.txt        실행 환경
prepare_redesign.py     이전 결과에서 파생 지도 자료를 만드는 코드
test_redesign.py        수치·앱 회귀검사
caption_audit.csv       기존 st.caption 12개 전수 검토
변경사항.md             이전 앱 문제와 재설계 내역
validation.json         수행한 검사와 미검증 범위
screenshots/            실제 데스크톱 브라우저 일부 화면 캡처
```

앱 실행에는 재분석이 필요하지 않습니다. `prepare_redesign.py`는 전체 기존 프로젝트의 상위 작업 폴더에서 실행하는 자료 준비 도구입니다. 배포용 단독 폴더에서 원자료 분석까지 수행하는 도구가 아닙니다. 전체 원자료 분석은 기존 전체 결과 ZIP에 보존했습니다.

## 화면과 필터
- 연구 소개: 중앙값에 가까운 실제 연도쌍. 필터 없음.
- 공간 변화: 종·조사구·연도 선택은 지도에 적용. 종 선택만 전체 기간 소실 후 요약에도 적용. 단독 점유 체크는 변화 지도에만 적용.
- 소실의 조건: 종·연도 범위·오분류 경고 조사구 제외를 주변·방목 비교에 함께 적용.
- 예측 비교: 동일한 평가 표본 400개로 고정. 재학습하지 않는 필터를 제거.
- 결론: 전체 자료의 세 질문에 대한 답과 적용 범위.
- 방법과 검증: 출처·관측 누락·민감도. 종 선택은 민감도 그래프에만 적용.

## 지표와 파생 지도
기본은 10cm·양의 다각형 교차 면적입니다. 같은 칸의 종 구성이며 정확히 같은 위치의 면적 교체가 아닙니다. 소실은 이전 점유 칸에서 다음 해 해당 종의 기록이 없는 경우입니다.

변화 지도는 다음 순서로 분류합니다: A 유지 → 다음 해 불확실 → 신규·기존 타종 함께 → 신규 타종 → 기존 타종만 → 다른 다각형 식물 기록 없음. 이전 해 식별 불확실이 있고 다음 해 타종이 있으면 신규 여부를 확정하지 않고 불확실로 표시합니다. 유지 중 불확실 동시 기록은 툴팁에 남깁니다. 회색 비교 대상 밖은 관측 누락이나 식물 부재가 아닙니다. 누락 연도쌍은 지도 선택지에 넣지 않고 관측표에서 보여줍니다.

A 단독 소실 후 요약은 이전 A-only 정의를 그대로 사용하므로 종별 194/69/38 사례 등 기존 수치가 보존됩니다. 전체 변화 지도는 기존 공존 칸도 보여주므로 이 요약과 모집단이 다릅니다. 주변 비교는 격자·연도 행 가중 비율이며, 조사구별 분포도 함께 제공합니다. 방목 공통 연도는 관측 상태표에서 결정합니다.

모델은 이전 시간순 학습·검증·평가를 그대로 사용합니다. 예측 모집단은 t년에 A만 기록된 칸이며 미래 A 소실 여부로 고르지 않았습니다. 미래 식별 불확실은 목표 판정에서 제외했습니다. AP 재표집 구간은 6개 목장에 대한 조건부 평가 불확실성으로 새 지역의 성능 보장이 아닙니다.

## 배포용 ZIP
`초원연구_재설계_배포.zip`을 풀면 루트에 `app.py`, `research.py`, `requirements.txt`, `.streamlit/`, `data/`가 있습니다. 배포 환경에는 이 파일과 폴더를 같은 루트에 놓고 진입점을 `app.py`, Python을 3.13으로 설정합니다. ZIP 안에는 사전 계산 자료가 포함되어 원자료 분석을 다시 수행할 필요가 없습니다.

기존 공개 사이트는 이 ZIP만 만든 시점에는 변경되지 않았습니다. 화면 캡처는 데스크톱 일부만 수행했으며 모바일 화면 확인은 완료되지 않았습니다. `validation.json`의 계산·앱 테스트와 화면 확인 범위를 구분해 보세요.
