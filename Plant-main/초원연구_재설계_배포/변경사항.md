# 이전 앱 검토와 변경사항

이전 버전: `final/revision/app.py`. 다섯 화면과 모든 사용자 설명, 필터 바인딩을 코드로 전수 검토하고 기존 12개 AppTest 결과를 참고했다. 이전 버전의 여섯 종류 자료·모델·관측표를 재사용한다.

| 이전 문제 | 변경 |
|---|---|
| 첫 화면부터 전처리·누락·표본 수 강조 | 연구 질문·자료의 생김새·실제 연속 지도로 시작 |
| 모든 화면에 7개 선택 항목 노출 | 해당 화면의 선택만 접힌 탐색 영역에 배치 |
| 두 해의 A 피복만 보여 교체 판단 불가 | 종 목록 비교를 추가해 유지·신규·기존·불확실 변화 지도 제공 |
| 소실 후 요약이 지도와 다른 모집단임을 이해하기 어려움 | 지도/전체 기간 요약의 적용 범위를 본문에 명시 |
| 주변 막대·표·상자·산점도 연속 나열 | 주변 질문·결과·해석 → 목장별 방목 질문 순서. 분포는 상세 열기 |
| 예측에 무효한 격자 필터와 전체 JSON 상시 노출 | 실험을 고정하고 예측 대상·정보 차이·지표 설명부터 제공 |
| 결론에 보고서 전문 출력 | 세 답변, 관측 제안, 한계만 편집 |
| 중요 설명을 회색 caption으로 처리 | 12개 전수 검토 후 본문 또는 방법 페이지로 이동. 새 caption은 출처에만 사용 |

색상은 유지=녹색, 신규=황토색, 기존=청색, 불확실=보라색, 무기록=회색으로 고정했다. 모든 상태는 텍스트 범례·툴팁도 제공한다. KPI 카드, 그림자, 아이콘, 의미 없는 부제를 추가하지 않았다. 학명은 임의의 한국어 이름으로 바꾸지 않고, 조사구 코드는 목장·방목 이력과 함께 표기한다.

대표 사례는 가장 많은 합산 피복을 가진 B. gracilis 중 초기 점유가 50칸 이상인 연도쌍의 소실률 중앙값에 가장 가까운 것으로 정했다. 결과를 극적으로 보이게 하려는 최대값 선택을 하지 않았다.

새 파생 계산은 10cm 칸별 이전·다음 종 목록의 차집합/교집합뿐이다. 기존 격자 피복, 전이 개수, 모델 확률·성능 파일은 바이트 일치로 보존을 확인한다. 불확실 기록 때문에 신규 여부가 모호하면 지도에서 불확실로 남긴다.

배포 상태와 화면 검수 완료 여부는 `validation.json`을 참조한다. 실제 화면 검수 전에는 CSS 작성이나 AppTest 통과만으로 모바일 검수를 완료했다고 표시하지 않는다.
